竞品监控 · 统计方法说明

数据范围

  • 四大交易所：Binance、OKX、Bitget、Bybit
  • 分别统计现货和永续合约，逻辑相同，仅 API 端点不同

候选筛选

  • 按 24h ticker 成交额排序，现货各取前 200 名，合约各取前 100 名
  • 排除大市值币（BTC、ETH、SOL 等）、稳定币、杠杆代币（UP/DOWN/BULL/BEAR）、法币对

1h K线

  • 取最近 2 根 1H K线，使用最后已收盘那根计算涨跌幅和成交额
  • 涨跌幅 = (最后收盘 − 前一根收盘) / 前一根收盘 × 100%
  • 成交额 = 最后已收盘 K线的 quote 计价成交量（USDT）
  • 若成交额为 0 或 K线不足 2 根，则排除该交易对

三种榜单

  • 成交额 / 涨幅 / 跌幅各取每所每市场 Top 3
  • 某币种连续在多次榜单出现时，会在其后标注近期在榜次数
